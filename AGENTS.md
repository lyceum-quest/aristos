# Project Instructions

## Tooling

- Implement project tooling and scripts in Roc.
- Declare tooling dependencies and runnable tasks in `Kaifile`.
- Run project tooling through Kai tasks or workflows.
- Do not introduce Python, Node.js, shell, or other scripting-language tooling when Roc and Kai can perform the work.
- Existing deployment shell scripts are legacy; do not expand them beyond what is required to invoke Roc/Kai tooling.
